# Argument, part 1

For q >= 0, write g_q(P) for the number of plane graphs on P with exactly q edges.

Fixed-edge input. Aichholzer, Hackl, Huemer, Hurtado, Krasser, and Vogtenhuber proved that point sets whose points all lie on their hull minimize the fixed-edge counts. If C_n is any n-point set with all points on the hull, then for every n-point set P in general position and every q >= 0,

g_q(P) >= g_q(C_n).                                      (1)
