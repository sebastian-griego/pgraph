# Argument, part 4

For sets with at most h hull vertices, use L_n = 3n - h - 3. Since M >= L_n, part 3 gives the same growth bound with M replaced by L_n whenever 0 <= a <= b <= L_n.

For a set C_n with all points on the hull, choose s boundary edges and d pairwise noncrossing diagonals. The Kirkman-Cayley formula gives

D(n,d) = 1/(d+1) binom(n-3,d) binom(n+d-1,d).
