# Argument, part 2

Rank growth. Suppose P has n points and r hull vertices. Each triangulation of P has M = 3n - r - 3 edges. For 0 <= q < M,

(q + 1) g_{q+1}(P) >= (M - q) g_q(P).                    (2)

Reason: count pairs (G,e), where G is a q-edge plane graph and e can be added to G. Every G extends to a triangulation, so it has at least M-q addable edges.
