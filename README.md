# Plane graphs with bounded hull

This repository is focused on one proof: for each fixed h >= 3, point sets with at most h hull vertices have strictly more plane graphs, in the exponential growth-constant sense, than point sets with all points on the hull.

The note proves the stronger bound

liminf m_h(n)^(1/n) >= 27/2 = 13.5 > 6 + 4 sqrt(2).

Read the proof in `proof.md`.
